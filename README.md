## 🎾 Jannik Sinner | Tribute Website

Welcome to the **Jannik Sinner Tribute Website**\! This project is a visual and informational tribute to **Jannik Sinner**, celebrating his inspiring journey from the Italian Alps to becoming the **World No. 1** tennis player. This single-page site features key milestones, quotes, and a call to dive deeper into his rise to the top of world tennis.

## Project Overview

The **Jannik Sinner Tribute Website** is a simple, responsive, and aesthetically clean landing page built with **HTML and CSS**. It showcases Sinner’s career highlights using text, layout styling, and image elements. This project serves both as a portfolio project and a tribute to one of tennis’s modern greats.

## Getting Started

### 1\. Clone the Repository

```bash
git clone https://github.com/yourusername/jannik-sinner-tribute.git
```

### 2\. Navigate into the Project Folder

```bash
cd jannik-sinner-tribute
```

### 3\. Open the HTML File

You can open the `index.html` file directly in any modern browser:

```bash
open index.html
# or
start index.html
```

### 4\. (Optional) Run a Local Development Server

Using Python:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`

Using VS Code Live Server Extension:

  - Open the folder in VS Code
  - Install and activate the Live Server extension
  - Click "Go Live" from the status bar
